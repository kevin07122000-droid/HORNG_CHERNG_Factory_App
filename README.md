# HORNG CHERNG Factory Management — iPhone Project

公司：HORNG CHERNG INDUSTRIAL CO., LTD.

這份專案已整理成 iPhone 建置流程。核心 App 程式在 `lib/main.dart`，
公司 Logo 在 `assets/horng_cherng_logo.jpeg`。

## 快速開始（Mac）
雙擊：
`iPhone_一鍵準備.command`

然後開：
`ios/Runner.xcworkspace`

完整說明請看：
`IPHONE_INSTALL_GUIDE.md`

## 目前版本
V2 MVP

### 已有功能
- 公司品牌登入頁
- Dashboard
- 生產工單
- 新增工單
- 材料庫存
- 進出貨
- QC 品管
- 圖面檔案選擇
- QR / 條碼掃描
- 料號詳細資料
- 本機資料儲存
